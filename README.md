# Cling Infotech — Homepage Redesign

A modern, responsive redesign of the Cling Infotech homepage, built as part of a frontend development assignment.

## Overview

The redesign focuses on presenting Cling's services, products, work, industries, innovation, leadership and company story through a clean editorial-tech visual system.

The goal was to create a professional interface that feels distinctive while remaining practical, readable and responsive.

## Highlights

- Responsive homepage layout
- Editorial-inspired visual design
- Interactive project filtering
- Interactive product showcase
- Interactive industries section
- Smooth section navigation
- Responsive contact form
- Company story, vision and mission
- Innovation and technology section
- Leadership section
- Responsive footer and contact information
- Mobile-friendly layouts

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Sanskriti12Ag/cling-redesign.git
```

Navigate into the project:

```bash
cd cling-redesign
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## Build

To create a production build:

```bash
npm run build
```

## Design Direction

The interface uses:

- Warm off-white backgrounds
- Charcoal typography
- Lime accent highlights
- Space Grotesk for headings
- DM Sans for body text
- Thin borders and structured grids
- Asymmetric editorial layouts
- Subtle motion and interaction

The design intentionally avoids excessive gradients, glassmorphism and decorative effects in favour of a cleaner product-focused visual language.
